이유: 복합표본 설계 특성상 특정 취약·소수 집단은 추정의 정확도를 높이기 위해 실제 인구 비율보다 더 높은 확률로 과대표집된다.
      따라서 가중치를 적용하지 않은 원자료(비가중)는 해당 집단이 과다 반영되어 있으며, 전체 인구 대표성을 갖추기 위해 과대표집된 표본에 낮은 가중치(<1)를 부여하여 보정한다.

- 변수별 이유:
읍면 거주: 표집 단계에서 농어촌/읍면 지역 표본이 소수 지역 추정 정밀도를 위해 직접적으로 과대표집되었다. 가중치 적용 시 인구 비율에 맞게 보정되어 비율이 대폭 감소하기 때문이다.
소득 1분위: 복지, 보건 정책 대상인 저소득층 현황을 세밀히 파악하고자 소득 하위 계층 표본을 과대표집하였다. 가중치를 부여해 전체 모집단의 소득 분포로 펴주면서 비율이 감소하기 때문이다. 
고혈압 유병률: 고혈압 변수 자체를 과대표집한 것은 아니지만 과대표집된 읍면 지역 및 고령층 표본에서 고혈압 유병 비율이 압도적으로 높았기 때문에, 가중치 보정으로 표본의 연령·지역 과대표집 편향이 해소되면서 유병률도 함께 크게 감소한다.
