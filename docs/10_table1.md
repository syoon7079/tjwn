### 각주
1. **n과 %의 뜻:** 범주형 변수는 n(가중 %)로 제시했다. n은 비가중 응답자 수이고, %는 `wt_ntr` 가중치를 적용해 각 열(전체 또는 외식 빈도군) 안에서 결측을 뺀 유효 응답 중 해당 범주의 비율이며, 각 변수의 범주 가중 %를 더하면 100%이다(노트북에서 확인).
2. **요약통계 근거:** 연령과 BMI는 가중 평균(SE)으로 요약했다. 분석 대상의 가중 왜도는 연령 ‹ ›, BMI ‹ ›으로 ‹평균이 적절하다고 판단한 이유를 출력값에 맞춰 한 줄로›. 연령은 80세 이상이 80으로 상단 코딩되어 있다.
3. **가중치·층·집락·도메인 분석:** 가중치는 `wt_ntr`(영양조사 가중치), 층은 `kstrata`(‹ ›개), 집락은 `psu`(‹ ›개)이다. SE는 층화·집락 복합표본 설계를 반영한 선형화(Taylor) 분산으로 구했다. 분석 대상은 전체 설계표본의 부분집단(도메인)으로 취급해 분산 계산에는 전체 설계표본의 층·집락 구조를 유지했다.
4. **외식 빈도 세 범주 기준(L_OUT_FQ, 주당 외식 횟수):** 저빈도 = 주 1-2회 이하(원 코드 5·6·7), 중빈도 = 주 3-4회(원 코드 4), 고빈도 = 주 5회 이상(원 코드 1·2·3).
5. **연구대상 연령:** 만 19세 이상 성인. 열 머리의 n은 비가중 인원이다.
6. **결측·무응답·비해당 처리:** 외식 빈도와 BMI가 유효하지 않은 사람은 분석 대상에서 제외했다. 공변량 결측은 대상자를 제외하지 않았고 변수별 "결측(n)" 행으로 제시했다(% 계산에서는 제외). 음주(BD1_11)와 흡연(BS3_1)의 코드 8(비해당)은 별도 범주로 유지했고, 모름·무응답(9)은 결측으로 처리했다. 비만은 BMI 25 kg/m² 이상으로 정의했다.
7. **자료:** 국민건강영양조사 제9기 3차년도(2024) 원시자료(HN24_ALL).
8. **해석 주의:** 외식 빈도군 간 차이는 횡단면에서 관찰한 관련성이며 인과적 효과를 뜻하지 않는다. 군 간 연령·소득·생활습관 차이는 11주차 DAG에서 교란 가능성을 검토할 근거일 뿐이며 Table 1만으로 교란변수를 확정하지 않는다.

## B-3 비가중 대 가중

같은 분석 대상과 같은 정의로 만든 비가중 표(범주: n(비가중 %), 연속형: 평균(SD))는 노트북 8번 셀 출력이다. 표 전체: ‹노트북 `table_unw` 출력으로 교체›

**비교 기준:** 표준화 차이(SMD) = |가중 − 비가중| / √((비가중 분산 + 가중 분산) / 2). 범주형은 범주별로 계산해 변수 안 최댓값을 쓰고, 연속형은 평균 차이로 계산했다. 전체 열에서 SMD가 큰 순서로 상위 3개를 골랐다.
