dag {
  EatOut [exposure]  BMI [outcome]  U [latent]
  Age -> {Educ Income Work HH1 EatOut BMI PA Smoking Alcohol}
  Sex -> {Income Work EatOut BMI PA Smoking Alcohol}
  Educ -> {Income Work EatOut BMI PA Smoking Alcohol}
  Region -> {Income Work EatOut BMI}
  Work -> {Income EatOut BMI Alcohol}
  Income -> {EatOut BMI}
  HH1 -> {EatOut BMI}
  U -> {EatOut PA Smoking}
  PA -> BMI
  Smoking -> BMI
  EatOut -> {Alcohol Energy BMI}
  Alcohol -> BMI
  Energy -> BMI
}

#C-1: 화살표마다 근거(시간 순서, 선행연구)를 말할 수 있어야 합니다.
| 화살표 | 근거 |
|---|---|
| 연령 → 교육, 소득, 근로, 1인 가구 | 출생 코호트에 따라 학력이 다름(시간 순서: 연령·코호트가 먼저). 생애주기에 따라 근로·소득·거주 형태가 달라짐 |
| 연령, 성별 → 외식 빈도 | Table 1에서 저빈도군은 평균 연령이 높고(57세 대 43세), 고빈도군은 남성 비율이 높음(66%) |
| 연령, 성별 → BMI | 연령·성별에 따른 체성분과 BMI 분포 차이는 선행연구에서 일관됨 |
| 교육 → 소득, 근로 | 학력이 취업과 소득에 선행 |
| 교육, 소득 → 외식 빈도 | Table 1에서 고빈도군은 대졸 이상(71%)과 소득 상위가 많음 (자료 확인) |
| 교육, 소득 → BMI | 사회경제적 수준과 비만의 관련은 선행연구에서 보고됨 |
| 지역 → 외식 빈도, BMI, 소득, 근로 | 도시·농촌에 따른 외식 환경(식당 접근성)과 일자리 구조 차이 |
| 근로 → 외식 빈도 | 직장인은 점심·회식 등으로 외식 기회가 많음 |
| 근로 → BMI | 근로 형태(좌식, 교대근무)가 체중에 영향 |
| 1인 가구 → 외식 빈도, BMI | 혼자 살면 조리 대신 외식·간편식을 택하기 쉽고, 식사 패턴이 BMI에 영향 |
| U → 외식 빈도, 신체활동, 흡연 | 건강 지향 성향은 식생활·운동·흡연에 공통으로 작용한다고 가정 (미측정) |
| 신체활동, 흡연 → BMI | 에너지 소비와 체중 조절에 대한 영향 |
| 외식 → 음주 → BMI | 외식·회식 자리에서 음주가 늘고, 알코올 열량이 BMI에 영향 (매개) |
| 외식 → 에너지 섭취 → BMI | 연구 가설의 핵심 경로 (매개) |

#C-1 역할 표와 보정집합: 공변량마다 교란·매개·충돌부 가운데 어느 역할인지와 근거를 적고, 추정 대상(총효과 또는 직접효과)에 맞는 최소 보정집합 정하기

| 변수명 (원변수) | DAG 상의 역할 | 근거 | 총효과 모형 보정 여부 |
| :--- | :--- | :--- | :--- |
| **외식 빈도** <br>(`L_OUT_FQ`) | **노출** | • 연구의 독립변수(원인 후보)<br>• 주간 섭취 빈도에 따라 저·중·고빈도로 분류됨[cite: 3, 4] | - (노출) |
| **체질량지수 BMI** <br>(`HE_BMI`) | **결과** | • 연구의 종속변수(결과)<br>• 외식으로 인한 열량 섭취 증가의 최종 건강 결과 지표[cite: 3, 4] | - (결과) |
| **성별** (`sex`) | **교란** | **근거**: 생물학적 특성은 외식 빈도와 대사율·체지방 분포(BMI)에 선행하여 영향을 미침[cite: 3, 4] | **보정함** |
| **거주 지역** (`region`) | **교란** | **근거**: 지역별 외식 인프라(식당 접근성)와 거주민의 식생활 환경 차이가 외식 빈도와 BMI에 영향을 미침[cite: 3, 4] | **보정함** |
| **교육수준** (`educ`) | **교란** | **근거**: 사회경제적 지위(SES)는 식습관 및 건강 인식을 결정하며 외식 빈도와 비만 유병률에 영향을 미침[cite: 3, 4] | **보정함** |
| **소득 4분위** (`incm`) | **교란** | **근거**: 경제적 자원(소득 수준)은 외식 소비 여력과 식품 선택에 직접 작용하며 BMI와도 연관됨[cite: 3, 4] | **보정함** |
| **음주 빈도** (`BD1_11`) | **교란** | **근거**: 외식 상황(회식, 모임 등)과 밀접하게 연동되어 외식 빈도에 영향을 미치며, 알코올 열량을 통해 BMI 대사에 관여함[cite: 3, 4] | **보정함** |
| **현재 흡연** (`BS3_1`) | **교란** | **근거**: 개인의 건강 관련 라이프스타일 지표로서 식생활 패턴(외식) 및 체중 조절 기전에 공통으로 작용함[cite: 3, 4] | **보정함** |
| **1인 가구** (`cfam`) | **교란** | 식사 방식과 BMI에 모두 영향 | **보정함** |
| **근로 여부** (`EC1_1`) | **교란** | 외식 기회와 BMI에 모두 영향 | **보정함** |
| **신체활동** (`pa_aerobic`) | **교란** | $U$의 영향을 BMI까지 전달하는 경로 위 변수 | **보정함** |
| **에너지 섭취** | **매개** | 연구 가설의 핵심 경로 | **보정함** |


**<추정 대상 및 최소 보정집합 설정>**

**1. 추정 대상 설정**  
본 연구에서는 외식 빈도(L_OUT_FQ)가 체질량지수(HE_BMI)에 미치는 총효과(Total Effect)를 추정 대상으로 설정하였다. 외식 빈도라는 행위가 식단 구성의 변화, 일일 총 에너지 섭취량 증가 등의 다양한 경로를 거쳐 최종적으로 체질량지수(BMI)에 미치는 종합적인 영향력을 평가하는 것이 본 연구의 목적이므로, 인과 경로 상의 매개변수를 통제하지 않고 노출이 결과에 미치는 전체적인 영향력을 측정하고자 하였다.

**2. 최소 보정집합 구성 및 근거**  
총효과를 올바르게 추정하기 위한 최소 보정집합에는 성별, 거주 지역, 교육수준, 소득 4분위, 음주 빈도, 현재 흡연 여부(및 연령)를 포함시켰다.

**3. 백도어 경로 차단**  
노출(외식 빈도)과 결과(BMI) 사이에 허위 연관성이나 왜곡된 상관관계를 발생시키는 인구사회학적 교란요인(성별, 지역, 교육수준, 소득)과 생활습관 교란요인(음주 빈도, 현재 흡연)을 통제함으로써 가짜 연관성을 만드는 백도어 경로를 차단하였다.

**4. 과다보정(Over-adjustment) 방지**  
"외식 빈도 → 에너지 섭취량 증가 → BMI 증가"로 이어지는 인과 경로 상의 명백한 매개요인(Mediator)인 에너지 섭취량은 총효과 추정의 왜곡을 막기 위해 보정집합에서 의도적으로 제외하였다.
