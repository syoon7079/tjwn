#dagitty.net에 넣은 코드

dag {
  EatOut [exposure]  BMI [outcome]  U [latent]
  Age -> {Educ Income Work HH1 EatOut BMI PA Smoking Alcohol}
  Sex -> {Income Work EatOut BMI PA Smoking Alcohol}
  Educ -> {Income Work EatOut BMI PA Smoking Alcohol}
  Region -> {Income Work EatOut BMI}
  Work -> {Income EatOut BMI Alcohol}
  Income -> {EatOut BMI}
  HH1 -> {EatOut BMI}
  U -> {EatOut PA Smoking}
  PA -> BMI
  Smoking -> BMI
  EatOut -> {Alcohol Energy BMI}
  Alcohol -> BMI
  Energy -> BMI
}

#C-1: 화살표마다 근거(시간 순서, 선행연구)를 말할 수 있어야 합니다.
| 화살표 | 근거 |
|---|---|
| 연령 → 교육, 소득, 근로, 1인 가구 | 출생 코호트에 따라 학력이 다름(시간 순서: 연령·코호트가 먼저). 생애주기에 따라 근로·소득·거주 형태가 달라짐 |
| 연령, 성별 → 외식 빈도 | Table 1에서 저빈도군은 평균 연령이 높고(57세 대 43세), 고빈도군은 남성 비율이 높음(66%) |
| 연령, 성별 → BMI | 연령·성별에 따른 체성분과 BMI 분포 차이는 선행연구에서 일관됨 |
| 교육 → 소득, 근로 | 학력이 취업과 소득에 선행 |
| 교육, 소득 → 외식 빈도 | Table 1에서 고빈도군은 대졸 이상(71%)과 소득 상위가 많음 (자료 확인) |
| 교육, 소득 → BMI | 사회경제적 수준과 비만의 관련은 선행연구에서 보고됨 |
| 지역 → 외식 빈도, BMI, 소득, 근로 | 도시·농촌에 따른 외식 환경(식당 접근성)과 일자리 구조 차이 |
| 근로 → 외식 빈도 | 직장인은 점심·회식 등으로 외식 기회가 많음 |
| 근로 → BMI | 근로 형태(좌식, 교대근무)가 체중에 영향 |
| 1인 가구 → 외식 빈도, BMI | 혼자 살면 조리 대신 외식·간편식을 택하기 쉽고, 식사 패턴이 BMI에 영향 |
| U → 외식 빈도, 신체활동, 흡연 | 건강 지향 성향은 식생활·운동·흡연에 공통으로 작용한다고 가정 (미측정) |
| 신체활동, 흡연 → BMI | 에너지 소비와 체중 조절에 대한 영향 |
| 외식 → 음주 → BMI | 외식·회식 자리에서 음주가 늘고, 알코올 열량이 BMI에 영향 (매개) |
| 외식 → 에너지 섭취 → BMI | 연구 가설의 핵심 경로 (매개) |

#C-1 역할 표와 보정집합: 공변량마다 교란·매개·충돌부 가운데 어느 역할인지와 근거를 적고, 추정 대상(총효과 또는 직접효과)에 맞는 최소 보정집합 정하기

| 변수 (원변수) | 역할 | 근거 | 모형 2 |
| :--- | :--- | :--- | :---: |
| **연령** (`age`) | 교란 | 외식과 BMI에 모두 선행하는 공통 원인 | 포함 |
| **성별** (`sex`) | 교란 | 위와 같음 (출생 시 결정) | 포함 |
| **교육** (`educ`) | 교란 | 성인기 외식 습관과 BMI에 선행하는 사회경제적 요인 | 포함 |
| **소득** (`incm`) | 교란 | 외식 지출 여력과 식생활·BMI에 모두 영향 | 포함 |
| **지역** (`region`) | 교란 | 외식 환경과 BMI에 모두 영향 | 포함 |
| **1인 가구** (`cfam` 등) | 교란 | 식사 방식과 BMI에 모두 영향 | 포함 |
| **근로 여부** (`EC1_1` 등) | 교란 | 외식 기회와 BMI에 모두 영향 | 포함 |
| **신체활동** (`pa_aerobic` 등) | 교란 대리지표 | $U$의 영향을 BMI까지 전달하는 경로 위 변수 | 포함 |
| **현재 흡연** (`BS3_1`) | 교란 대리지표 | 신체활동과 같은 논리 | 포함 |
| **음주** (`BD1_11`) | 매개 | 외식 → 음주 → BMI. 외식의 후손이라 총효과에서는 제외. 포함하면 외식과 다른 음주 원인 사이에 충돌부 편향도 생김 | 제외 |
| **에너지 섭취** | 매개 | 연구 가설의 핵심 경로 | 제외 (모형 3 후보) |
| **충돌부** | 없음 | 보정집합 안에서 열리는 충돌부 경로 없음 (노트북 d-분리 확인) | - |



| 변수명 (원변수) | DAG 상의 역할 | 세부 인과적 판정 및 근거 | 총효과 모형 보정 여부 |
| :--- | :--- | :--- | :--- |
| **외식 빈도** <br>(`L_OUT_FQ`) | **노출 (Exposure, X)** | • 연구의 독립변수(원인 후보)<br>• 주간 섭취 빈도에 따라 저·중·고빈도로 분류됨[cite: 3, 4] | - (노출) |
| **체질량지수 BMI** <br>(`HE_BMI`) | **결과 (Outcome, Y)** | • 연구의 종속변수(결과)<br>• 외식으로 인한 열량 섭취 증가의 최종 건강 결과 지표[cite: 3, 4] | - (결과) |
| **성별** (`sex`) | **교란요인 (Confounder)** | • **판정**: 교란요인<br>• **근거**: 생물학적 특성은 외식 빈도와 대사율·체지방 분포(BMI)에 선행하여 영향을 미침[cite: 3, 4] | **보정함** |
| **거주 지역** (`region`) | **교란요인 (Confounder)** | • **판정**: 교란요인<br>• **근거**: 지역별 외식 인프라(식당 접근성)와 거주민의 식생활 환경 차이가 외식 빈도와 BMI에 영향을 미침[cite: 3, 4] | **보정함** |
| **교육수준** (`educ`) | **교란요인 (Confounder)** | • **판정**: 교란요인<br>• **근거**: 사회경제적 지위(SES)는 식습관 및 건강 인식을 결정하며 외식 빈도와 비만 유병률에 영향을 미침[cite: 3, 4] | **보정함** |
| **소득 4분위** (`incm`) | **교란요인 (Confounder)** | • **판정**: 교란요인<br>• **근거**: 경제적 자원(소득 수준)은 외식 소비 여력과 식품 선택에 직접 작용하며 BMI와도 연관됨[cite: 3, 4] | **보정함** |
| **음주 빈도** (`BD1_11`) | **교란요인 (Confounder)** | • **판정**: 교란요인 (생활습관 공변량)<br>• **근거**: 외식 상황(회식, 모임 등)과 밀접하게 연동되어 외식 빈도에 영향을 미치며, 알코올 열량을 통해 BMI 대사에 관여함[cite: 3, 4] | **보정함** |
| **현재 흡연** (`BS3_1`) | **교란요인 (Confounder)** | • **판정**: 교란요인 (생활습관 공변량)<br>• **근거**: 개인의 건강 관련 라이프스타일 지표로서 식생활 패턴(외식) 및 체중 조절 기전에 공통으로 작용함[cite: 3, 4] | **보정함** |
